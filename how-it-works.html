How the Launch Hub Works

A guide to managing retail product launches - from timeline to tasks to creative requests.

Overview
What is the Launch Hub?
The Launch Hub is a centralised view for each Port Store product launch. Rather than switching between multiple Monday.com boards, spreadsheets, and emails - everything for a launch lives in one place: timeline, tasks, shoots, graphic requests, video requests, product assortment, resources, and notes.

It connects live to Monday.com, so changes made in any source board (ASA Hub, Graphic Design Workflow, Video/Photography board) are reflected automatically. Nothing is duplicated - the hub just surfaces what's relevant to the launch.

Home Screen
Navigating launches
The home screen shows all launches grouped by status. Click any card to open its hub.
1
Live Now
Launches whose date is today. These appear at the top with a pulsing green dot.
2
Upcoming
Launches with a future date, sorted chronologically. Tap to open the hub and start preparing.
3
Past
Launches whose date has passed. Still accessible - useful for referencing what was done.
4
+ New Launch
Creates a new launch entry in Monday.com and takes you straight into it. Just enter a name, date, and time.
💡
Each launch card shows the number of open tasks and how many are assigned to you specifically.
Launch Hub
Inside a launch
The hub is split into two tabs - Launch Hub (the content view) and Tasks. The hub tab contains the following sections in order:
📅
Launch Timeline
Key dates and milestones for the launch. Linked photoshoots are pulled in automatically as teal entries.
📸
Photoshoots & Video
Link shoots from the ASA/CBA Hub and video/photo requests from the Video board. Read-only - edit in the source boards.
🎨
Graphic Design Requests
Link requests from the Graphic Design Workflow board. Shows status, request date, and file links. Read-only.
🔗
Resources
Website links (with live/not live status) and asset links for graphics, photography, and storytelling.
🛍️
Full Product Assortment
The complete product grid for the launch. Upload product images directly - stored in Monday.com.
📌
Important Notes
Key information, warnings, and reminders for the team. Colour-coded by severity.
💡
Use the launch switcher dropdown in the top bar to jump between launches without going back to the home screen.
Tasks
Managing launch tasks
The Tasks tab has a two-panel layout. Department summary cards on the left, task list on the right. Click a department card to filter to just that department's tasks.
1
Adding a task
Click + Add Task. Fill in the task name, department, assignee(s), due date, and any details. The task is created in Monday.com immediately.
2
Updating status
Use the coloured pill dropdown on each task card to change status. Cycling to Completed will prompt you to optionally set a completed date.
3
Editing or deleting
Use the Edit button to update any task detail including the completed date. Use Delete to remove it permanently from Monday.
4
Managing departments
Click ⚙️ Departments to add or remove departments. These are shared across all launches and stored in Monday.com.

Photoshoots & Video
Linking shoots and video requests
This section pulls from two source boards - the ASA/CBA Hub for player shoots and the 2026 Video/Photography Workflow board for video and photo requests. Nothing is edited here - it's read-only and updates automatically every 60 seconds.
1
Link a shoot
Click + Link Shoot to choose a shoot from the ASA/CBA Hub Requests group. The shoot date, players, location, and status appear on the card.
2
Link a video/photo request
Click + Link Video/Photo to choose a request from the Video/Photography board. Only Retail and Media & Marketing department requests are shown. Past-due requests are excluded.
3
Remove a link
Click Remove on a card to unlink it. This does not delete anything in the source board - it just removes it from this launch view.
⚠️
To edit shoot or video request details, go to the source board directly using the View in ASA Hub ↗ or View in Board ↗ links on each card.
Graphic Design Requests
Linking graphic requests
Links to items in the Graphic Design Workflow board. Only Marketing and Port Store department requests are shown in the picker. Past-due items are excluded. Details update automatically from the source board.
1
Link a request
Click + Link Request and choose from the dropdown. The list shows the request name and due date for upcoming Marketing and Port Store requests.
2
Request new graphics
Click + Request Graphics ↗ to open the graphic request form in Monday.com directly.
3
File links
If asset files have been attached in Monday, they'll appear as File 1 ↗, File 2 ↗ links. If nothing is attached yet it shows "Not available".
Products
Managing the product assortment
A grid of all products in the launch. Images are uploaded directly and stored in Monday.com - no external CDN needed.
1
Add a product
Click + Add Product. Enter the product name and Port Store URL, then choose an image file (JPG, PNG, or WebP). Recommended square crop, under 800KB.
2
Copy the Port Store link
Each product card has a Copy Link button for quick sharing. A "Not live yet" badge shows if no URL has been added.
3
Replace an image
Open Edit on any product and choose a new image file. The existing image will be replaced. If you don't pick a new file, the existing image is kept.
Resources
Links and assets
Resources are split into two types - Website Links (Port Store, BigCommerce, etc.) with live/not live status, and Asset Links (graphics, photography, storytelling) with a View button.
💡
Mark a website link as "Not live yet" to show a badge on the card - useful for flagging pages that aren't published yet.
My Tasks
Cross-launch task view
The My Tasks button on the home screen opens a view showing all tasks across all launches, pre-filtered to you. This is useful for seeing everything assigned to you without switching between launches.
1
All launches in one view
All tasks from every launch are loaded. Each card shows a small ⚡ launch tag so you know which launch it belongs to.
2
Filter by launch
Use the Launch filter in the filter bar to narrow to a specific launch. All other filters (status, department, assignee) work the same way.
3
Update status directly
You can change task status from My Tasks - the change saves back to Monday immediately regardless of which launch the task belongs to.
💡
My Tasks is automatically pre-filtered to whoever is logged into Monday.com when the app loads. You can clear the assignee filter to see everyone's tasks.
Tips
Things worth knowing
💾
Caching for speed
The app caches data in your browser session - the launch board for 2 minutes, external boards for 5 minutes. This means repeat visits are much faster. The cache refreshes automatically every 60 seconds in the background, and is always updated when you make changes.
🔗
Linking vs editing
Shoots, video requests, and graphic requests are linked to a launch - not duplicated. Removing a link doesn't delete the item from its source board. To edit them, use the "View in Board" links to go to the source.
🏷️
Departments are shared
The department list is shared across all launches and stored in Monday.com. Adding or removing a department in ⚙️ Departments affects all launches.
📱
Works on mobile
The hub is responsive and works on mobile within Monday's app. The sidebar collapses to a single column on narrow screens.
🔒
Data lives in Monday
Everything - tasks, products, notes, resources, linked request IDs - is stored in your Monday.com board. The app is just a front-end. You can always view or edit the raw data directly in Monday.
